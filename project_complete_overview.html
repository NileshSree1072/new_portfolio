AI Layer — Hybrid Architecture
Azure OpenAI
Duplicate Detection (RAG)
Every ticket is converted to a 3072-dimensional vector using text-embedding-3-large. pgvector cosine similarity search finds past resolved tickets above 0.88 threshold. If match found, Groq generates a contextual reply using matched tickets as context.
Groq — llama-3.3-70b
AI Draft Reply + Summarization
Agents get a pre-generated draft reply based on similar past tickets and knowledge articles. Long threads can be summarized in 3-4 sentences. All chat completions routed through Groq (free, 6000 RPM) to avoid Azure quota issues.
pgvector
Semantic Search
Users search before submitting — AI finds semantically similar resolved tickets and knowledge articles even when exact words don't match. IVFFlat index makes search fast at scale without scanning every row.
Caffeine Cache + @Retryable
Reliability Layer
Embeddings cached for 24 hours to reduce API calls. @Retryable with 60 second backoff on failures. @Async processing so ticket creation responds instantly while AI runs in background. Circuit breaker degrades gracefully on AI outage.

What Makes This Project Stand Out for Seniors
Hybrid AI Architecture
Azure for embeddings (quota-limited but working) + Groq for chat (free, fast) — real-world constraint-driven decision, not textbook. Shows you can adapt to infrastructure limitations.
Fair Performance System
Late-assignment detection, transfer-aware SLA, system vs agent fault attribution — this is a problem real companies struggle with. Solving it correctly shows systems thinking beyond CRUD.
Self-improving Knowledge Base
Every resolved ticket can become a knowledge article. Every article improves AI accuracy. The system gets smarter over time without retraining — a genuine flywheel, not a gimmick.
Production-grade Design Decisions
Soft deletes, @Async AI processing, embedding caching, circuit breaker pattern, role-scoped data access, Flyway migrations — each decision has a real reason behind it you can explain to any senior.
